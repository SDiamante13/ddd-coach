## Findings (fresh-eyes pass)

1. **"what is DDD?" never cites validly (medium, prompt).** 0 of 3 runs cited a verbatim title. Run 1 gave a general answer with **no Source line and no "General practice" label** (an uncited definition, the thing #58 targets). Runs 2 and 3 invented a title, which the guard replaced. v13 names "what is DDD?" as a question to cite, yet also says "If no single section fits, cite nothing", and the Reference has no section called "Domain-Driven Design". A candidate for the next prompt or the eval: add a "what is DDD?" fixture with a check that requires either a valid Source line or the not-covered sentence.
2. **The guard label reads as a caption on the next line (low, UX).** "General practice: not from the Reference." renders in the same paragraph as "Paste a thread, meeting notes or code…", joined by a single line break. It sits after the answer, so it reads as labelling the call to action rather than the definition above. It's worth putting the label on its own line, with the same quiet style as the Source line.
3. **The Source line isn't the last line (low).** Both bounded-context replies put "Paste a thread…" after the Source line. v13 says "end that answer with one line". It still parses, and the `citation` block renders mid-reply.
4. **Copy the conversation leaves an extra blank line where the Source line was (cosmetic).** The copy has "…pick and pack.\n\n\nPaste a thread…".
5. **Step 5's RFC check is weak on hosted by construction.** "Copy for your RFC" only appears under three-part thread replies, which never carry citations, so "Source:" ×0 there is expected. The "Copy first" check (finding 4) is the one that proves a real Source line gets stripped.
6. **Tooling:**
   - `record stop` leaves the default context with the cookie, so the off-video session was already unlocked and needed no second password fill.
   - `netlify logs --function chat --json` lags by minutes: Duration and warn lines for the last calls were missing on two checks.
   - `eval` runs in global scope, so a repeated `const` fails ("Identifier 'r' has already been declared"). Wrap every measurement in an IIFE.
